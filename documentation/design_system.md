# SK-MarketHub Flipkart Signature Design System Specification

**Brand:** SK-MarketHub  
**Tagline:** SHOP SMART. LIVE BETTER.

Flipkart Signature Blue & Yellow visual identity enforced across **SK-MarketHub Web** (React + TypeScript) and **SK-MarketHub Android** (Java + XML Views).

---

## 1. Flipkart Signature Palette Specifications

| Color Role | Hex Code | Usage Scope |
| :--- | :--- | :--- |
| **Primary Brand Blue** | `#2874F0` | Main App Header / Primary Navigation / Key Buttons / Splash Background |
| **Secondary Dark Blue** | `#1751A8` | Sub-navbars / Hover States / Accent Containers |
| **Accent Action Yellow** | `#FFE11B` | Action Badges / Search CTA Button / Cart Counter / Promo Highlights |
| **Page Background** | `#F1F3F6` | Off-White Surface Background for Web & Android |
| **Surface White** | `#FFFFFF` | Product Cards / Dialogs / Input Fields |
| **Selling Price Green** | `#388E3C` | Selling Price Text / Discount Badges (`X% OFF`) / In-Stock Indicators |
| **Text Primary** | `#212121` | Product Titles / Headings / Primary Text |
| **Text Secondary** | `#878787` | MRP Strikethrough / Captions / Helper Text |
| **Error Red** | `#D94B4B` | Errors / Wishlist Active Heart Icon |

---

## 2. Component Styling Rules

- **Header:** Electric Blue (`#2874F0`) with white text and Action Yellow (`#FFE11B`) accents.
- **Hero Banner:** Electric Blue (`#2874F0`) with `#FFE11B` promo CTA button.
- **Product Cards:** Aspect ratio image container, `#878787` brand/SKU text, `#212121` product title, `#388E3C` selling price, `#878787` MRP strikethrough, and `#2874F0` Add-to-Cart button with `#FFE11B` text!
