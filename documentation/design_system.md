# SK-MarketHub Premium Splash & Design System Specification

**Brand:** SK-MarketHub  
**Tagline:** SHOP SMART. LIVE BETTER.

Luxury Black-Navy and Metallic Gold visual identity enforced across **SK-MarketHub Web** (React + TypeScript) and **SK-MarketHub Android** (Java + XML Views).

## 2. Splash Screen Monogram Specification

- **Symbol:** SK Monogram inside an elegant Shopping Bag outline with rounded handle curves.
- **Coloring:** Gradient from Metallic Gold (`#D4AF37`) to Champagne Gold (`#E7B85C`).
- **Glow & Reflection:** Subtle radial gold aura (`rgba(212, 175, 55, 0.2)`) and light sweep across the emblem.
- **Brand Title:** `SK-MarketHub` in Champagne Gold (`#E7B85C`).
- **Tagline:** `SHOP SMART. LIVE BETTER.` in Soft Gold (`#F5D994`).
- **Progress Indicator:** Rotating Metallic Gold ring (`#D4AF37`) with status messages ("Initializing SK-MarketHub...", "Connecting securely...").
